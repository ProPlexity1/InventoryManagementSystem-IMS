# Inventory Management System

A full-stack SaaS inventory management system for small businesses.

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: .NET 9 Web API
- Database: PostgreSQL
- Auth: JWT Authentication + BCrypt

## Features
- User registration and login
- Each user has their own private inventory
- Add, view, and delete inventory items
- Dashboard with total items and total inventory value
- Secure JWT protected API endpoints
